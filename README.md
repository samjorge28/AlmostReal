AlmostReal – La botiga del futur
En què consisteix el projecte?
AlmostReal és un projecte que busca modernitzar les botigues de roba mitjançant la tecnologia, la intel·ligència artificial i la realitat virtual. La idea principal és crear una rèplica digital en 3D d'una botiga física, que els clients puguin visitar des d'un ordinador o amb unes ulleres de realitat virtual, com si estiguessin dins de la botiga real.
Per crear aquest espai virtual, es podria gravar la botiga amb un mòbil o un dron i utilitzar eines de reconstrucció 3D per generar un model inicial. Després, es podria editar amb Blender i incorporar-lo a Unreal Engine, on es crearia l'entorn interactiu.
Idees i funcions principals
Botiga virtual en 3D: els clients podrien caminar per la botiga virtual i veure on es troba cada peça de roba.
Mode PC i realitat virtual: es podria explorar la botiga amb el teclat i el ratolí o amb ulleres de realitat virtual, per tenir una experiència més immersiva.
Assistent virtual amb IA: un assistent podria respondre preguntes com ara «On són les dessuadores negres?» o «Quin conjunt em recomanes per sortir?».
Recomanacions de roba: el sistema podria recomanar conjunts segons els colors, l'estil, la talla i el pressupost del client.
Mapa i rutes: quan el client triés una peça, el sistema la destacaria dins de la botiga virtual i li mostraria el camí per arribar-hi.
Control d'estoc: una base de dades permetria consultar els productes disponibles, les talles, els colors i la seva ubicació.
Panell d'administració: els treballadors podrien gestionar els productes, actualitzar l'estoc i consultar informació de la botiga.
Com es podria desenvolupar?
Per fer el projecte, es podrien utilitzar diferents eines:
Blender: per crear i modificar els models 3D.
Unreal Engine: per construir la botiga virtual interactiva i el mode de realitat virtual.
Python: per programar algunes funcions de la IA i la comunicació entre sistemes.
MySQL o PostgreSQL: per guardar els productes, les talles i l'estoc.
Linux Server: per allotjar els serveis i la base de dades.
HTML, CSS i JavaScript: per crear el panell web d'administració.
Part d'informàtica i xarxes
Com que és un projecte del cicle de SMX, també es treballaria la part d'infraestructura informàtica. Es podria configurar un servidor Linux, una base de dades, una xarxa local, adreces IP, usuaris i permisos, mesures de seguretat i sistemes de monitoratge per comprovar que els serveis funcionen correctament.
Objectiu final
L'objectiu és crear una demostració funcional d'una botiga de roba intel·ligent on un client pugui entrar en un entorn 3D, parlar amb un assistent d'IA, rebre recomanacions i trobar els productes fàcilment. No caldria construir una botiga completa des del principi: es podria començar amb una versió petita i anar afegint funcions a mesura que avanci el projecte.
AlmostReal vol demostrar com es poden combinar la realitat virtual, la intel·ligència artificial, les bases de dades, els servidors i les xarxes per crear una nova manera de comprar roba.
